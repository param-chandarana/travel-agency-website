# TravelVista

**TravelVista** is a responsive and visually engaging frontend for a travel agency website built using **HTML5**, **CSS**, **JavaScript**, and **Bootstrap**. It showcases a wide variety of tour packages, including domestic, international, featured, and special tours, with detailed individual package pages.

## ✨ Features

### 🧳 Tour Categories
- **Domestic Tours** – Explore popular travel destinations within the country
- **International Tours** – Handpicked packages for world travelers
- **Featured Tours** – Highlighted and trending travel packages
- **Special Tours** – Seasonal or themed travel experiences

### 📄 Individual Package Pages
Each package includes:
- **Travel dates and duration**
- **Day-by-day itinerary**
- **Package highlights**
- **Inclusions & exclusions**
- **Call-to-action buttons** for inquiry or booking (static in this version)

### 🎨 Design & Layout
- Built with **Bootstrap 5** for responsive, mobile-first design
- Clean and modern UI with smooth transitions
- Cross-browser compatibility and semantic HTML5
